A beautiful, responsive, and interactive frontend website for a modern cafe. Built from scratch using HTML, CSS, and vanilla JavaScript.

## ✨ Features

* **Responsive Design:** Fully optimized for desktops, tablets, and mobile screens.
* **Interactive Menu:** Clean grid layout displaying cafe items with smooth hover effects.
* **Dynamic Cart/Booking:** JavaScript-powered features for a smooth user experience (e.g., interactive booking form or cart notifications).
* **Smooth Navigation:** Clean, modern navbar with smooth scroll behavior across sections.
* **Testimonials & Reviews:** A dedicated section displaying customer feedback.

---

## 🛠️ Technologies Used

* **HTML5:** Semantic markup for structured content.
* **CSS3:** Custom styling, Flexbox/Grid layouts, and smooth animations.
* **JavaScript (ES6):** Client-side interactivity and logic.
